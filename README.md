# DevOps notes

Здесь собраны основные определения, которые чаще всего спрашивают на собеседовании по Middle/Middle+ DevOps. В зависимости от уровня компании, материалов может хватить и для подготовки к Senior DevOps.

Не стоит воспринимать данные материалы как учебник. За учебной информацией лучше обратиться к LLM и документации соответствующих продуктов. Здесь можно найти более полный набор определений и примеров, которые помогут для повторения материала перед собеседованием.

Также, вы можете использовать эти материалы как план для обучения. Отправьте репозиторий вашему агенту, и он сможет провести полное обучение по упомянутым в документах понятиям.
